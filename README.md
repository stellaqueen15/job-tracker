# Job Tracker

Une application pour suivre des jobs / candidatures, avec un backend Node.js et un frontend Next.js + Tailwind.

---

## 📁 Structure du projet

job-tracker/
├─ frontend/ # Next.js + Tailwind
├─ backend/ # Node.js + Express + SQLite
├─ .gitignore
└─ README.md

---

## 🚀 Installation

### 1. Cloner le repo

```bash
git clone https://github.com/TON-USERNAME/job-tracker.git
cd job-tracker
```

### 2. Installer les dépendances

cd backend
npm install

cd ../frontend
npm install

### 3. Lancer le projet

cd backend
npm run dev

cd frontend
npm run dev

Frontend sur http://localhost:3000, backend sur http://localhost:3001

🔧 Tech Stack

Frontend: Next.js 13, Tailwind CSS

Backend: Node.js, Express, SQLite

Auth / Gmail: Gmail API OAuth2
